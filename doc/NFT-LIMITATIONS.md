Notable limitation of 'nft' command:

* Unable to display GARP Announcement (My new IP address is ... )  cannot do 'arp saddr ip == arp daddr ip'
* multiple '-f' CLI options only takes the last '-f' options; it does not daisy chain; useless for merging test
* all matching \*\_block delimiters must be within a single NFT script file; no spanning its matching block delimiters across 2 files.)
